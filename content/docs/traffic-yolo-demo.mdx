这个 demo 展示智慧交通系统的两个主要界面：配置道路监控场景与 ROI 区域，以及在 Web 监控台查看车辆检测、跟踪和交通事件信息。

## ROI 场景配置

视频展示场景配置界面：选择视频源，绘制道路区域，并配置导流区等监控区域，为后续交通规则判断提供空间范围。

## Web 交通监控台

Web 界面汇总道路监控状态、车辆数量和事件统计，并在监控画面中展示车辆检测框、跟踪 ID、车道和区域信息。视频本身是演示录屏，界面中的统计数据用于展示功能流程。
