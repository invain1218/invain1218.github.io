所有 token 定义在 `src/app/globals.css` 的 `@theme` 里，改一个值全站生效。

## 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `accent` | `#2452e3` | 电光蓝 —— 只用于链接、悬停、标签、编号 |
| `ink` | `#141414` | 标题 / 正文 |
| `ink-soft` | `#575757` | 次要文字 |
| `ink-faint` | `#8f8f8f` | 弱化文字 / 元信息 |
| `paper` | `#fafaf8` | 页面背景（暖白） |
| `surface` | `#ffffff` | 卡片 / 代码块 |
| `line` | `#e7e6e2` | 描边 / 分隔线 |

对应 Tailwind 类：`text-accent`、`text-ink-soft`、`border-line`、`bg-paper`。

原则：**全站几乎单色，accent 只在链接 / 悬停 / 小标签 / 编号出现**，不做彩色卡片墙。

## 字体层级

| 层级 | 尺寸 | 用途 |
| --- | --- | --- |
| Display | 72–92px | Hero 姓名 |
| H1 | 48–64px | 页面标题 |
| H2 | 32–40px | 区块标题 |
| H3 | 20–24px | 条目标题 |
| Body | 16–18px | 正文 |
| Caption | 12–14px | 元信息 / 标签 |

- 标题：`font-semibold` + `tracking-tight`（Geist）
- 标签 / 编号 / 日期：**等宽字体（mono）**，大写 + 宽字距，营造「科学笔记」质感

## 间距

Tailwind 4px 基准。区块之间大留白 `py-24` ~ `py-28`，内容最大宽度 `1200px`，左右 `px-6 sm:px-10 lg:px-16`。

## 圆角

**锐角为主**（不用胶囊 / 大圆角）。仅图片和代码块用 `rounded`（4px）。

## 断点（响应式）

| 档位 | 宽度 |
| --- | --- |
| Mobile | < 640px |
| Tablet | 640–1024px |
| Desktop | ≥ 1024px |

桌面基准 1440×900，平板 768×1024，手机 390×844。
