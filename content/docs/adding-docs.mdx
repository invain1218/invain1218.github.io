文档全部是 `content/docs/` 目录下的 `.mdx` 文件，**新增一个文件就会自动出现在 `/docs` 列表里**，无需改任何路由代码。

## 三步新增

1. 在 `content/docs/` 新建 `我的文档.mdx`（文件名即 URL，建议英文小写加连字符，如 `my-note.mdx`）；
2. 文件顶部写 frontmatter：

```yaml
---
title: 我的文档标题
description: 一句话简介（会显示在列表里）
date: 2026-01-20
tags: ["标签一", "标签二"]
---
```

3. 下面直接写 Markdown / MDX 正文。

## 支持的语法

- `#` 到 `####` 标题
- 段落、`-` 无序列表、`1.` 有序列表
- `**加粗**`、`*斜体*`、`` `行内代码` ``
- `[链接](https://…)`
- 表格（GitHub 风格，已开启 `remark-gfm`）
- 代码块（用三个反引号包起来）
- MDX 组件（可以直接写 JSX）

## 表格示例

| 参数 | 说明 |
| --- | --- |
| `title` | 文档标题 |
| `description` | 列表页显示的一句话简介 |
| `date` | 日期（用于排序） |
| `tags` | 标签数组 |

> 提示：文件名即 URL 的 `slug`，重复会覆盖；日期用于倒序排列。
