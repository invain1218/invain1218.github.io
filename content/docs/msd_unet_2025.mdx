<a id="basic-concepts"></a>
## 医学图像分割要解决什么

医学图像分割的基本输出是**像素级（二维）或体素级（三维）的掩膜**：模型为图像中的位置标注类别，有些任务还会给每个独立目标分配实例编号。因此，“像素/体素级”和“对象/实例级”不是两种互斥的分割单位：实例分割仍然输出像素或体素组成的掩膜，只是额外区分了每一个对象。

医学影像中常见的分割对象包括：

- **器官与解剖结构**：如肝脏、脾脏、心脏、血管或脑区；
- **病灶与异常区域**：如肿瘤、结节、出血或病变组织；
- **细胞与显微结构**：如单个细胞、细胞核或组织切片中的结构。

根据是否区分同类目标中的每个个体，常见任务可这样理解：

- **语义分割（semantic segmentation）**：逐像素或逐体素预测类别。属于同一类别的多个目标会得到相同类别标签，不单独标识个体。例如，将图像中的肝脏区域标为“肝脏”。
- **实例分割（instance segmentation）**：除了预测类别，还区分同类中的每个独立目标。例如，将多个细胞分别标为“细胞实例 1、细胞实例 2……”。每个实例依然由像素或体素掩膜表示。
- **全景分割（panoptic segmentation）**：组合语义类别与实例身份；通常对可数的独立目标区分实例，并为连续背景或区域赋予语义类别。

**多类与多标签**描述的是标签之间的关系，属于另一条划分维度：多类任务通常要求每个像素或体素只能属于一个类别；多标签任务允许同一位置同时属于多个掩膜，例如器官掩膜和肿瘤掩膜可以重叠。它们与是否区分实例并非同一概念。

这里的“对象”指任务中需要定位和勾画的结构或病变，具体范围由标注方案决定。若只预测图像级类别、中心点或边界框而没有像素/体素掩膜，通常属于分类、检测或定位任务，而不是分割。

<a id="prediction-output"></a>
### 从影像到掩膜：模型实际预测什么

以三维 CT 为例，输入通常是一个带有空间几何信息的体数据。网络在每个位置输出各类别的分数（logits），再将分数转换成类别概率并得到掩膜。多类任务通常对类别维做 `argmax`；二分类常用 `sigmoid`，再依据阈值生成前景掩膜。

```text
输入 CT：       [batch, channel, depth, height, width]
网络输出 logits：[batch, class, depth, height, width]
标注标签：      [batch, depth, height, width]
预测掩膜：      对每个体素选择概率最高的类别
```

二维切片模型把 `depth` 维移出模型输入，每次处理一个平面；三维模型则在卷积中直接利用相邻切片的空间上下文。体素不是各向同性的“立方像素”：CT/MRI 常有不同的层间距与平面内间距，因此重采样、网络感受野和表面距离评估都要考虑物理空间坐标。

### 医学影像分割为什么难

- **边界不清楚**：不同组织的灰度或信号可能相近，部分容积效应也会让边缘变模糊。
- **目标大小悬殊**：大器官和小病灶同时存在，背景体素常远多于目标体素。
- **解剖差异与采集差异**：患者个体、扫描设备、协议和医院之间都会造成分布变化。
- **标注本身有不确定性**：专家对模糊边界可能存在分歧；精细标注的时间成本也很高。
- **三维空间并非等距**：层间距与平面内像素间距可能不同，忽略物理空间会影响建模和评估。

因此，分割结果不仅取决于网络结构，也受标注规范、采集协议、类别比例和数据代表性影响。理解这些约束，才能判断某个架构改进解决了什么问题。

<a id="method-evolution"></a>
## 从规则与先验到深度学习

深度学习兴起之前，医学图像分割大致沿两类路线发展：

1. **基于图像的方法**直接利用图像强度、边缘或局部区域信息进行划分，代表方法包括水平集、主动轮廓、图割、模糊连通性和分水岭变换。
2. **基于模型的方法**把先验知识编码进统计形状与外观模型、几何模型或图谱（atlas）框架中，再据此约束分割。

基于图像的方法强调局部影像证据，基于模型的方法显式加入先验。卷积神经网络（CNN）则推动了端到端分割的发展，U-Net 成为经典基线。之后，Transformer 通过自注意力建模较远位置之间的关系，形成 TransUNet、Swin Transformer、UNETR 等结构；SAM 及 MedSAM 等医学影像适配工作进一步探索提示驱动和跨任务迁移。方法不断变化，但核心挑战始终是结合足够的上下文，同时保留定位边界所需的细节。

<a id="unet-foundations"></a>
## U-Net 的结构基础

### 编码器与解码器

编码器逐步压缩空间尺寸并提取更抽象的语义特征；解码器逐步恢复空间分辨率，将语义信息映射回像素或体素级预测。自编码器也采用类似的编码—解码结构，但分割网络的目标是预测标签，而不一定重建输入。

将二维图像直接展平为一维向量会丢失空间邻接关系。卷积自编码器利用卷积操作保留局部空间结构，FCN、SegNet 和 U-Net 等分割网络也由此发展出更适合视觉任务的编码器—解码器设计。

```text
输入 x → Encoder → 潜在特征 z → Decoder → 预测结果 ŷ
```

编码器负责建立表征，解码器负责恢复预测所需的空间布局。对分割而言，跳跃连接（skip connection）会把编码器的高分辨率特征传给解码器，帮助恢复边界和小结构。

用一个简化的二维输入说明 U-Net 的信息流：图像从 `256×256` 开始，每次下采样让宽高减半、通道数增加；解码器逐级上采样，并与同分辨率的编码器特征融合。真实网络的通道数和层数会因实现而异。

```text
编码器：256² → 128² → 64² → 32² → 16²
         特征细节逐步减少，语义上下文逐步增强
解码器： 16² →  32² → 64² → 128² → 256²
         每一级融合对应编码器的高分辨率特征
输出头：1×1 卷积把最终特征映射为 K 个类别的 logits
```

原始 U-Net 的跳跃连接会**拼接（concatenate）**两路特征，再用卷积进行融合；ResNet 残差块通常做**逐元素相加（addition）**。拼接保留两路特征供后续卷积学习如何组合，但会增加通道数和显存占用。两种连接的目的也不同：U-Net 主要传递定位细节，残差连接主要让深层网络更容易传递和优化特征。

### 多尺度特征

不同大小的结构需要不同尺度的上下文。网络越深，特征通常具有更强的语义表达，但空间分辨率更低；浅层特征定位较精细，却较难独立判断结构的整体含义。多尺度方法尝试融合这些互补信息。

常见网络由三部分组成：

- **Backbone（主干）**：提取从边缘纹理到高层语义的分层特征。
- **Neck（特征融合）**：整合主干各层、各尺度的特征。FPN（Feature Pyramid Network）是常见设计之一。
- **Head（任务头）**：根据任务输出类别、边界框或分割掩膜。

FPN 通过自底向上的主干特征、自顶向下的上采样路径，以及横向连接来融合不同层级的信息。横向分支通常先用 $1\times1$ 卷积调整通道数，再与上采样特征逐元素相加，之后用卷积平滑特征图。

![多尺度特征金字塔概念](/images/msd/figure-06.png)

```text
Backbone：C2, C3, C4, C5（分辨率逐级降低，语义逐级增强）
                         ↓ 自顶向下上采样
FPN：     P2, P3, P4, P5（跨层融合后的多尺度特征）
```

![FPN 自顶向下路径与横向连接](/images/msd/figure-07.png)

### 注意力机制

注意力机制根据输入内容调整特征的重要性。常见的卷积注意力可粗略分为通道注意力、空间注意力和自注意力：

- **通道注意力**为不同特征通道分配权重，例如 SE 模块（SE-Net）。
- **空间注意力**强调图像中的相关位置，例如 CBAM 中的空间注意力分支。
- **自注意力（self-attention）**通过 Query、Key、Value 之间的关系建模位置间的上下文联系，是 Transformer 的核心机制之一。

在注意力门（Attention Gate）中，输入特征会乘以经过 Sigmoid 映射的门控权重，从而减弱部分位置或通道的响应。注意力机制提供的是一种特征重加权方式；效果仍取决于任务、数据和具体结构。

![通道、空间与自注意力示意](/images/msd/figure-08.png)

### 按标注信息划分学习范式

- **全监督学习**使用像素级或体素级标注。通常监督信号直接，但医学标注需要专业人员投入大量时间，结果也会受到标注一致性影响。
- **半监督学习**使用少量有标注数据和更多无标注数据，目标是在减少精细标注需求的同时利用无标注样本。
- **弱监督学习**使用比完整掩膜更粗略的标注，例如图像级标签、框或涂鸦。
- **无监督学习**不依赖人工分割标签，尝试从图像结构或数据分布中发现区域。

![不同监督范式所需的标注信息](/images/msd/figure-09.png)

编码器—解码器、多尺度特征和注意力解释了网络如何构造预测；监督范式则回答模型从哪里获得学习信号。先看最直接的全监督路线，再看精细标注有限时的半监督方法。

<a id="fully-supervised"></a>
## 全监督分割

全卷积网络（FCN）使用卷积层替代分类网络中的全连接预测头，使网络能够输出与图像空间位置对应的密集预测。U-Net 进一步采用对称的编码器—解码器路径，并通过跳跃连接融合浅层细节与深层语义，因此在医学分割中被广泛采用。

<a id="training-objectives"></a>
### 训练目标：交叉熵与 Dice 的互补作用

多类交叉熵逐像素（或逐体素）惩罚错误类别，优化稳定且直接；但当前景很小、背景占绝大多数时，背景容易主导总损失。Dice 损失直接衡量预测区域与标注区域的重叠，对前景比例较小的任务通常更敏感。常见的组合基线是 `L = L_CE + λ L_Dice`，其中 `λ` 控制两部分的相对权重。

```text
Dice(P, G) = 2 × |P ∩ G| / (|P| + |G|)
L_Dice     = 1 - Dice(P, G)
```

这里 `P` 是预测前景，`G` 是人工标注。实际训练会对软概率计算可微的 Dice，并通常加入平滑项避免空掩膜时分母为零。若任务包含多个前景类别，还需要说明 Dice 是逐类计算后宏平均，还是先汇总所有体素再计算；两种口径可能给出不同结论。

U-Net 的改进并非单纯堆叠模块，而是围绕几个信息流问题展开：编码器怎样提取语义，瓶颈层怎样汇总上下文，解码器怎样恢复细节，以及跳跃连接怎样筛选跨层信息。

### 编码器

**残差连接与密集连接**改善深层网络的信息传递。残差块学习输入与变换结果的残差映射；Dense 结构让一层直接接收前面多个层级的特征。它们都可能改善优化与特征复用，但会带来额外计算或显存开销。

**卷积变体**则从感受野和特征尺度入手：

- 空洞卷积在不同比例上采样卷积核，以较少新增参数扩大感受野；过于规则的空洞率可能产生栅格效应，可通过混合空洞率缓解。
- Inception、ASPP 等并行分支使用不同卷积核或空洞率提取多尺度上下文。
- 小波下采样等方法尝试在降采样时保留更多结构信息。

### 瓶颈层

瓶颈层通常位于编码器与解码器之间，特征分辨率较低、语义信息较集中。可以通过扩大感受野或汇总全局上下文，帮助网络判断局部结构在整体解剖中的位置。

常见设计包括空洞卷积、ASPP、金字塔池化、非局部模块和全局自注意力。它们的共同目标是补充局部卷积难以直接覆盖的远距离关系，但计算成本和适用数据规模各有差异。

### 跳跃连接：控制浅层信息的传递

跳跃连接可以弥补下采样造成的定位信息损失，但浅层特征也可能携带背景噪声。Attention U-Net 一类方法在融合前加入注意力门，筛选与解码目标更相关的特征；其他方法则通过多尺度或全尺度连接融合不同层级的信息。

### Transformer 与卷积—Transformer 混合网络

Transformer 以自注意力建立远距离位置之间的关系。UNETR、Swin-UNet 等将 Transformer 用于编码或多尺度特征提取；混合架构则保留卷积对局部结构的建模能力，同时引入注意力获取更大范围的上下文。

| 路线 | 主要优势 | 主要代价与风险 | 常见适用起点 |
| --- | --- | --- | --- |
| CNN / U-Net | 局部归纳偏置强、结构直接；有限数据下容易训练和复现 | 远距离关系主要靠堆叠层或额外上下文模块建立 | 作为新数据集的透明基线，尤其在数据量和显存有限时 |
| Transformer / 混合网络 | 更直接地建模远距离上下文；混合模型兼顾卷积细节 | 计算和显存需求较高；收益受预训练、数据规模和实现影响 | 有足够预训练或数据资源，且任务确实需要长程上下文时 |
| 提示式基础模型 | 可用点、框或交互提示适配不同目标，支持人工修订 | 域差异可能导致掩膜偏差；提示和人工校正成本也要计入 | 交互式标注、迁移学习或需要专家参与的工作流 |

这张表用于选择实验起点，不构成性能排序。应先确定任务瓶颈，再通过同数据划分和同评估协议的实验比较模型。

<a id="worked-example"></a>
### 一个端到端例子：三维 CT 器官与病灶分割

假设目标是从腹部 CT 中分割肝脏和肝脏内的病灶。一个可复现的基线流程可以按下面的顺序搭建：

1. **按患者划分数据**：同一患者的切片或检查不能同时出现在训练集和测试集，否则相邻图像会造成数据泄漏。
2. **统一空间与强度处理**：读取体素间距和方向信息；按任务设定重采样与 CT 强度裁剪/归一化，并把同一套变换应用到图像和标签。
3. **采样三维 patch**：训练时从体数据裁出固定大小的 patch；增加含病灶或前景的采样机会，避免模型几乎只看到背景。
4. **训练多类 3D U-Net**：输出背景、肝脏和病灶的类别分数，使用交叉熵与 Dice 的组合损失。
5. **恢复完整体数据预测**：推理时使用重叠滑窗覆盖大体积，融合窗口概率后再映射回原始空间，并保留方向和间距信息。
6. **按患者评估**：分别报告肝脏和病灶的 Dice 与边界距离指标，同时检查小病灶漏检、空标签病例和跨中心表现。

这是一个用于解释流程的基线示例，不是固定处方。不同任务的扫描协议、目标大小、标签定义和数据量都会影响预处理及采样选择。

<a id="semi-supervised"></a>
## 半监督分割：降低对精细标注的依赖

全监督路线依赖像素级或体素级标签，但医学标注昂贵且耗时。半监督分割因此将少量有标注样本与更多无标注样本结合，尝试在减少精细标注需求的同时维持预测质量。常见策略包括一致性正则、伪标签和先验知识，实际模型也经常组合这些方法。

![半监督分割方法概览](/images/msd/figure-39.png)

### 一致性正则

对同一无标注图像施加不同增强或扰动，模型应给出相互一致的预测。比较前需要把预测变换回相同的坐标系。约束可以作用于：

- **数据层**：不同增强视图的输出保持一致。
- **特征层**：不同视图的中间特征或嵌入保持相似，也可以采用对比学习。
- **模型层**：通过教师—学生或模型集成，使预测对模型扰动更稳定。

Mean Teacher、FixMatch 和 FeatMatch 等工作展示了相关思路。具体效果取决于增强是否符合医学图像的成像特点，以及一致性约束是否会强化错误预测。

以教师—学生方法为例，教师通常由学生参数的指数移动平均得到。教师对弱增强图像产生较稳定的目标预测，学生则学习在强增强图像上复现该预测。比较前必须把预测和增强变换对齐到同一坐标系；置信度门槛可以屏蔽低可信体素，但门槛过高会丢掉难例，过低则会引入错误伪标签。

```text
有标签样本：图像 + 真值掩膜 → 监督损失
无标签样本：弱增强 → 教师预测 → 对齐/筛选 → 监督强增强下的学生
总损失：    监督损失 + λ × 一致性损失
```

![一致性正则的典型流程](/images/msd/figure-40.png)

![数据、特征与模型层的一致性](/images/msd/figure-41.png)

### 伪标签

模型先为无标注图像生成预测，再将足够可信的预测作为伪标签参与训练。**自训练**通常由一个模型迭代更新自己的伪标签；**协同训练**则可由不同模型或视图互相提供伪标签。置信度筛选有助于减少噪声，但模型也可能反复强化自己的偏差。

![伪标签训练流程](/images/msd/figure-42.png)

![自训练与协同训练](/images/msd/figure-43.png)

### 先验知识

医学影像包含解剖形状、空间位置、相对尺度、组织边界和生理过程等信息。方法可以把先验作为网络输入、学习目标或正则项，例如形状先验、拓扑约束、图谱信息和时间序列先验。先验的价值取决于它与目标人群、采集协议和任务定义是否匹配。

![医学影像先验知识的类型](/images/msd/figure-44.png)

![半监督学习中的先验约束](/images/msd/figure-45.png)

综述提到的代表性半监督方法包括 UA-MT、FixMatch、CPS、DTC、MC-Net、URPC、UniMatch、UniMatch V2 和 SAMatch。它们采用的监督信号和架构不同，阅读时可重点比较数据划分、伪标签策略、增强方式和评价协议。

<a id="research-directions"></a>
## 从模型结构到泛化与工作流

前面的章节聚焦于单个模型如何产生分割结果，以及如何利用未标注数据训练。更广的研究问题还包括：数据覆盖了哪些人群和病种、模型能否跨设备与机构泛化、预测是否能表达不确定性，以及模型如何嵌入临床工作流。以下趋势分别从数据、任务、模型和使用方式展开。

### 从全监督走向半监督与无监督

一条路线是建设更大、标注更规范的公开数据集，以支持全监督训练和可比较的评估；另一条路线是更充分地利用未标注影像，降低精细标注的成本。综述举例包括 MSD、AbdomenAtlas-8K、AMOS、BTCV 和 BraTS 等数据集。使用这些数据集时仍需核对其任务定义、标签范围和许可条款。

### 从器官分割扩展到病灶分割

病灶在大小、形态和边界上往往更不规则，且类别分布可能高度不平衡。因此，小目标召回、边界质量、跨中心泛化和标注一致性是值得单独检查的问题。综述提供了器官与病灶数据集的整理图，供进一步检索。

![器官分割数据集概览](/images/msd/figure-46.png)

![病灶分割数据集概览](/images/msd/figure-47.png)

### 从单模态走向多模态与域适应

不同成像模态、医院和扫描协议之间存在分布差异。多模态领域适应（MMDA）关注如何利用不同模态或来源之间的互补信息，并降低域偏移造成的性能下降。评估时应区分同分布测试与跨中心、跨设备或跨模态测试。

### 从任务专用模型走向提示式基础模型

SAM 等基础模型带来了提示驱动的分割范式，医学领域也出现 MedSAM 等适配工作。预训练模型可以作为迁移学习起点，但自然图像与医学影像之间的差异、提示形式、标注成本和目标任务仍需要在具体数据上评估。

### 从单一预测走向不确定性估计

确定性模型给出一个预测结果；概率式方法还尝试表示预测的不确定性。集成、Monte Carlo Dropout、贝叶斯方法和概率校准可以帮助研究者检查模型何时不确定。概率输出本身并不保证校准良好，仍需结合适当指标与外部验证。

### 从二维走向三维与四维

三维模型能够利用体数据中的空间上下文，四维任务还可能建模时间变化；与此同时，体素数量、显存需求和各向异性分辨率也带来工程挑战。二维切片、2.5D 与三维方案之间需要结合数据量、结构尺度和计算资源权衡。

| 输入方式 | 输入内容 | 能利用的信息 | 典型限制 |
| --- | --- | --- | --- |
| 2D | 单张切片 | 切片内的平面结构 | 不直接建模相邻切片关系；体积连续性可能较差 |
| 2.5D | 目标切片及其相邻若干切片 | 少量层间上下文 | 输入通道/邻片数需设定；远距离三维关系有限 |
| 3D | 三维 patch 或完整体数据 | 体素间的三维空间上下文 | 显存开销大；需处理各向异性 spacing 与 patch 覆盖 |
| 4D | 三维体数据随时间变化的序列 | 空间与时间动态 | 数据、标注和计算需求更高，评估还需考虑时间一致性 |

选择时应从体素间距和目标形态出发。例如，层间距远大于平面内间距时，直接使用各向同性 3D 卷积并不一定合适；可以考虑各向异性卷积核、重采样，或先用 2.5D 建立对照基线。

### 从模型调用走向分割智能体

语言驱动或工具协作的系统尝试根据临床意图规划分割、调用模型并允许专家交互修订。此类工作更像是围绕模型建立工作流，结果仍需专业人员检查，且需要评估可追溯性、失败恢复和工作流安全性。

<a id="practical-checklist"></a>
## 从数据处理到可靠评估

架构选择只是实验流程的一部分。数据划分、预处理、采样、损失函数、推理方式和评估协议共同决定结果是否可信。下表适合作为基线检查清单，具体配置仍需根据任务验证：

| 环节 | 可优先检查的事项 |
| --- | --- |
| 数据 | 训练、验证和测试划分是否按患者隔离；体数据的 spacing、窗宽窗位或强度标准化是否一致 |
| 采样 | 类别不平衡是否严重；patch 采样是否能覆盖小结构与前景区域 |
| 增强 | 旋转、翻转、弹性形变、强度偏移、噪声是否符合成像和解剖约束 |
| 网络 | U-Net 可作基线；三维小批量训练可评估 InstanceNorm 或 GroupNorm |
| 损失 | Dice 与交叉熵常作为组合基线；类别不平衡时可比较 Focal 或 Tversky，边界敏感任务可评估边界损失 |
| 推理 | 大体积输入可采用滑窗推理与重叠区域融合；测试时增强应报告其设置 |
| 评估 | 除 Dice 外，可报告 HD95、ASSD 等边界指标，并说明空掩膜和类别聚合的处理方式 |
| 可靠性 | 检查跨中心泛化、校准和不确定性；保存预处理、模型与评价配置以便复现 |

<a id="segmentation-metrics"></a>
### 如何读分割指标

- **Dice** 衡量预测掩膜与真值的重叠，取值通常在 0 到 1 之间，越高表示重叠越大。小目标即使只偏差几个体素，也可能造成明显下降。
- **IoU（Jaccard）**也是重叠指标。对于同一对二值掩膜，`Dice = 2 × IoU / (1 + IoU)`，因此 Dice 与 IoU 高度相关，不能当作两种独立证据。
- **HD95** 计算预测表面与真值表面之间的对称距离，再取第 95 百分位数，常用于减少单个离群点对最大 Hausdorff 距离的支配。它的单位应是毫米等物理长度，计算前必须正确处理体素间距。
- **ASSD** 汇总两组表面点到对方表面的平均距离，反映整体边界偏差；它也依赖空间间距和表面提取方式。

重叠指标无法完整描述边界误差，边界指标也无法单独说明结构覆盖是否充分。推荐逐类报告，并说明病例级聚合方式、空真值/空预测的处理规则和单位；必要时列出病例分布或置信区间，避免平均值掩盖少数严重失败病例。

<a id="controlled-comparison"></a>
### 实验比较需要控制什么

比较模型时，应固定患者级数据划分、预处理、训练预算和后处理，再报告验证集选择规则。公开基准上的分数只在相同标签定义、数据划分和评估脚本下才具有可比性。对于跨中心应用，还应把目标中心作为独立外部测试，检查性能变化，而不是只从随机划分的同源测试集推断泛化能力。

训练和推理策略需要根据目标结构、标注质量、数据规模与计算资源验证。医学任务尤其应避免仅凭单一数据集或单一指标推断临床可用性。

<a id="summary"></a>
## 把架构、数据与评估放在一起

医学图像分割要把影像映射为像素级或体素级标签；U-Net 通过编码器提取语义、解码器恢复空间分辨率，并用跳跃连接传递定位细节；多尺度和注意力模块进一步处理上下文与特征融合；半监督方法则在精细标注有限时引入无标注数据。

因此，架构改进常围绕三件事展开：**更有效地提取语义、更准确地恢复边界与细节、更合理地融合不同层级和尺度的特征。**但模型结构不能替代高质量数据、跨域验证和透明的评估协议。最终应把架构、监督信号与评估设计作为一个整体来判断。
